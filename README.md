# :meat_on_bone: The Odin Project - Recipes

The Odin Project Recipes is a basic HTML website built as part of The Odin Project’s Foundations course. It includes a homepage linking to individual recipes with images, descriptions, ingredient lists, and step-by-step instructions. This project helped me practice HTML structure, relative links, images, and lists.

## :pencil: Features

- Homepage with links to recipes.
- Recipe pages with images, ingredients and instructions.
- Navigation back to homepage.

## :iphone: Tech Stack

- HTML
- Git and GitHub

## :eyeglasses: How to view it

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
